# Contributing to GoToSocial Plus

GoToSocial Plus is a small fork that stays close to
[GoToSocial](https://codeberg.org/superseriousbusiness/gotosocial).

- Report Plus-specific problems in this repository.
- Report problems that also affect unmodified GoToSocial to the
  [upstream issue tracker](https://codeberg.org/superseriousbusiness/gotosocial/issues).
- Discuss non-trivial changes in an issue before opening a pull request.
- Keep changes focused, tested, documented, and easy to carry across upstream
  updates.
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

Use the
[upstream contribution guide](https://codeberg.org/superseriousbusiness/gotosocial/src/branch/main/CONTRIBUTING.md)
for build, development, formatting, and test instructions.
