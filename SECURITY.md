# Security Policy

GoToSocial Plus stays close to upstream GoToSocial and adds a small set of
optional changes. Please report vulnerabilities to the project responsible for
the affected code.

## GoToSocial Plus vulnerabilities

For a vulnerability introduced by a Plus-specific change, email
[hello@fischr.org](mailto:hello@fischr.org). Please do not open a public issue
until a fix or safe disclosure plan is available.

Include the affected Plus version, configuration, reproduction steps, impact,
and any suggested mitigation you can safely share. Never include real access
tokens, private keys, personal data, or credentials.

## Upstream GoToSocial vulnerabilities

If the vulnerability also affects an unmodified GoToSocial release, follow the
[upstream security policy](https://codeberg.org/superseriousbusiness/gotosocial/src/branch/main/SECURITY.md)
instead. At the time this policy was written, upstream asks for security reports
at `admin@gotosocial.org`.

If you are unsure whether an issue is Plus-specific, report it privately to the
Plus contact above. It can then be coordinated with upstream without making the
issue public prematurely.
